 # Python Calculator 🧮

My first Python project — a simple calculator built using Python.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Checks for invalid operators

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download `calculator.py`.
3. Open a terminal in the file's folder.
4. Run:

```bash
python calculator.py
```
